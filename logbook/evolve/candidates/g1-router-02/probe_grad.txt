Reading: at init the router learns almost only through the EMA dechunker's credit at SELECTED positions (the premise
of g1-router-02); exploration moves that credit onto positions the deterministic top-k would never evaluate, at a
comparable total gradient.

Caveat found on the way: hnet.analysis.grad_audit --text reads the file from byte 0, and the mix_v1 *.bytes.bin val
files start with a 1024-byte binary header (zeros). Audits fed that file directly have one degenerate all-zero window
(it gets a single chunk under batch-rank decisions, and that chunk's EMA credit dominates the router gradient). The
audits in this directory use the header-stripped text.
